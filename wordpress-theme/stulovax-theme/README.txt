Stulovax WordPress Theme

What is included:
- front-page.php for the homepage
- page-about.php for the About page when the page slug is about
- shared header/footer
- copied site CSS and JS assets

Setup steps in WordPress:
1. Go to Appearance > Themes > Add New > Upload Theme.
2. Upload the zip of the stulovax-theme folder.
3. Activate the theme.
4. Go to Pages > Add New and create a page named About.
5. Make sure the About page slug is exactly about.
6. Visit Settings > Permalinks and use Post name if not already enabled.
7. Optionally visit Settings > Reading and set a static homepage if you want WordPress to manage a Home page entry, though front-page.php will already control the site root.
